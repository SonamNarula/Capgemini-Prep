## 1. Understand the Problem

Return all unique triplets `[a, b, c]` with `a + b + c = 0`. No duplicate triplets in the output.

**Clarify:** Does order within a triplet matter? Fewer than 3 elements → empty?

## 2. Brute Force

Triple nested loop over all `i < j < k`, store sorted triplets in a `set` to dedupe.

## 3. Brute-Force Complexity

Time `O(n³)` (+ log for the set), Space `O(k)`.

## 4. Bottleneck

Searching for the third number linearly. Sorting lets us find a pair for a fixed first element with two pointers in `O(n)`.

## 5. Optimal Approach (and why it works)

Sort. Fix `nums[i]`; find pairs in `(i+1..n-1)` summing to `-nums[i]` using `l`/`r`. Sum too small → `l++`, too big → `r--`. On a hit, record and skip duplicates on `l`, `r`. Skip duplicate `nums[i]` values too. Break early once `nums[i] > 0`.

**Complexity:** Time `O(n²)`, Space `O(1)` extra (ignoring output and sort).

## 6. Clean C++ Code

*(assume `#include <bits/stdc++.h>` and `using namespace std;`)*

```cpp
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    int n = nums.size();
    vector<vector<int>> res;
    for (int i = 0; i < n - 2; i++) {
        if (nums[i] > 0) break;                          // no way to reach 0
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // skip duplicate anchors
        int l = i + 1, r = n - 1;
        while (l < r) {
            long long sum = (long long)nums[i] + nums[l] + nums[r];
            if (sum < 0) l++;
            else if (sum > 0) r--;
            else {
                res.push_back({nums[i], nums[l], nums[r]});
                l++; r--;
                while (l < r && nums[l] == nums[l - 1]) l++;
                while (l < r && nums[r] == nums[r + 1]) r--;
            }
        }
    }
    return res;
}
```

## 7. Dry Run

`[-1, 0, 1, 2, -1, -4]` → sorted `[-4,-1,-1,0,1,2]`

- `i=0` (`-4`): best pair sum is `-1+2=1 < 4` → every step `l++`, nothing found
- `i=1` (`-1`): `l=2 (-1)`, `r=5 (2)` → sum `0` ✓ `[-1,-1,2]`; `l=3 (0)`, `r=4 (1)` → sum `0` ✓ `[-1,0,1]`
- `i=2`: duplicate of `-1` → skip
- `i=3` (`0`): `0+1+2=3 > 0` → `r--` → done

## 8. Edge Cases

- All zeros `[0,0,0]` → one triplet `[0,0,0]`
- Fewer than 3 elements → `[]`
- All positive or all negative → `[]`
- Heavy duplicates `[-2,0,0,2,2]` → `[[-2,0,2]]` once
- Large values: use `long long` for the sum
